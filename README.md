# Techno Bundle — ورژن ۷

PWA فارسی و راست‌چین برای طراحی باندلینگ توسن تکنو.

## ویژگی‌ها
- نام برنامه: Techno Bundle
- لوگوی توسن تکنو برای صفحه آغازین و آیکن برنامه
- صفحه آغازین ۵ ثانیه‌ای با عنوان «طراحی باندلینگ»
- فونت یکان (فایل فونت همراه پروژه است)
- نمای مدیریت و کارگزار، خروجی CSV و چاپ/PDF
- صفحه فارسی فرمول‌ها
- پیشنهاد هوشمند کارگزار: اولویت بیشترین تعداد کارتخوان و سپس کمترین قیمت؛ پیشنهاد ارتقا فقط تا ۱۰۰ میلیون تومان بالاتر از بودجه و فقط اگر از نظر هدف بهتر باشد
- بودجه بازاریابی به قیمت پیش از باندلینگ اضافه می‌شود و دوباره از بودجه باندلینگ کش‌لس کسر نمی‌شود

## اجرا
فایل‌ها را در ریشه مخزن GitHub قرار دهید و GitHub Pages را برای انتشار فعال کنید. چون برنامه از ماژول‌های جاوااسکریپت استفاده می‌کند، از بازکردن مستقیم فایل `index.html` با `file://` خودداری کنید.

## توجه مالی
موتور محاسبات `engine.js` از نسخه قبلی حفظ شده است تا ساختار محاسبات پایه تغییر نکند. پیش از استفاده عملیاتی، تست‌های `tests/engine.test.js` و سناریوهای تجاری ورژن ۷ را اجرا و خروجی پیشنهاد هوشمند را با محدودیت‌های نهایی کسب‌وکار تطبیق دهید.
